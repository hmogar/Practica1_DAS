### Descripción de Roles
* **Arquitectos Software Senior (ASS):** Identifican los problemas de diseño, plantean y capturan las decisiones de diseño en formato MADR (estilos arquitectónicos, patrones de diseño, clases, etc.).
* **Arquitectos Software Cognitivos (ASC):** Cuestionan y discuten las decisiones tomadas por los ASS, planteando nuevos problemas o alternativas.
* **Arquitecto Software Junior (ASJ):** Modela y documenta la arquitectura software en diagramas UML de clases y paquetes en base a las decisiones de diseño acordadas.

## Estructura del Repositorio

El repositorio está organizado de la sigueiente forma:

```text
.
├── Requisitos/               # Tablas de requisitos funcionales y de dominio
│   ├── Semana_1/             # Análisis inicial
│   ├── Semana_2/             # Modificaciones y refinamientos
│   └── Semana_3/             # Requisitos consolidados finales
│
├── Decisiones/               # Registro de decisiones de diseño en formato MADR
│   ├── templates/            # Plantillas estándar MADR v4.0.0 y ADR inicial
│   ├── Semana_1/             # Decisiones iniciales
│   ├── Semana_2/             # Decisiones de refinamiento de diseño y paquetes
│   └── Semana_3/             # Decisiones finales hasta completar el diseño
│
└── Arquitecturas/            # Modelos de arquitectura en UML
    ├── Semana_1/             # UML del estilo arquitectónico seleccionado
    ├── Semana_2/             # Refinamiento con clases y paquetes
    └── Semana_3/             # Arquitectura software final completa
```
